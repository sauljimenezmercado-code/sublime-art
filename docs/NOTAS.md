# Notas del proyecto

## Decisiones iniciales

- El sitio se construye sin framework.
- El catálogo se administra desde `assets/js/products-data.js`.
- El número de WhatsApp se configura únicamente en `assets/js/config.js`.
- Los datos comerciales no confirmados se mantienen como pendientes.
- Las imágenes reales se incorporarán posteriormente.
